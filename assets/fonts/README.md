# فونت وزیرمتن

فونت فارسی سایت، به‌صورت فایل محلی (بدون CDN) تا روی هر هاستی بدون وابستگی به اینترنت خارجی کار کند.

| مورد | مقدار |
|---|---|
| فایل | `Vazirmatn-Variable.woff2` |
| نسخه | v33.003 |
| نوع | فونت متغیر (Variable) — وزن ۱۰۰ تا ۹۰۰ در یک فایل |
| حجم | حدود ۱۰۸ کیلوبایت |
| مجوز | SIL Open Font License 1.1 — متن کامل در `LICENSE-Vazirmatn.txt` |
| سازنده | صابر راستی‌کردار — https://github.com/rastikerdar/vazirmatn |

## چرا فونت متغیر؟
یک فایل ۱۰۸ کیلوبایتی همه وزن‌ها را پوشش می‌دهد، در حالی که سه فایل جدا
(معمولی، متوسط، توپر) روی هم حدود ۱۵۰ کیلوبایت و در سه درخواست جدا بارگذاری می‌شدند.

## به‌روزرسانی
فایل جدید را از صفحه Releases دانلود کنید، `Vazirmatn[wght].woff2` را از پوشه
`fonts/webfonts` بردارید و با نام `Vazirmatn-Variable.woff2` جایگزین کنید.
نام فایل عمداً بدون براکت است چون براکت در آدرس بعضی سرورها مشکل ایجاد می‌کند.
