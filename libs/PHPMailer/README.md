# PHPMailer

کتابخانه ارسال ایمیل، به‌صورت **فایل مستقیم** و بدون Composer.

| مورد | مقدار |
|---|---|
| نسخه | v6.9.3 |
| مجوز | LGPL-2.1 — متن کامل در `LICENSE` |
| منبع | https://github.com/PHPMailer/PHPMailer |

## فقط سه فایل لازم است
از کل کتابخانه فقط این سه فایل برای ارسال با SMTP نیاز است:

- `PHPMailer.php` — کلاس اصلی
- `SMTP.php` — ارتباط با سرور SMTP
- `Exception.php` — کلاس خطا

فایل‌های دیگر (OAuth، POP3، DSNConfigurator) برای این پروژه لازم نیستند و اضافه نشده‌اند.

## روش استفاده
این فایل‌ها مستقیماً استفاده نمی‌شوند؛ کلاس `App\Core\Mailer` آن‌ها را بارگذاری
و تنظیمات SMTP را از جدول `settings` می‌خواند.

## به‌روزرسانی
نسخه جدید را از صفحه Releases دانلود کنید و همین سه فایل را از پوشه `src`
جایگزین کنید. نیازی به تغییر کد پروژه نیست.
