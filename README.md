# Itecho — فروشگاه اینترنتی

فروشگاه اینترنتی موبایل، کامپیوتر، کنسول بازی، تجهیزات گیمینگ و لوازم جانبی.

## استک فنی

| مورد | انتخاب |
|---|---|
| بک‌اند | PHP خام + PDO (بدون فریم‌ورک) |
| دیتابیس | MySQL / MariaDB |
| فرانت | HTML + CSS + JavaScript خالص، RTL و ریسپانسیو |
| میزبانی | Shared Hosting (cPanel) — بدون نیاز به SSH، Composer، Node.js یا Docker |
| درگاه پرداخت | زرین‌پال (فعلاً حالت Sandbox) |
| ایمیل | Gmail SMTP با PHPMailer (نسخه بدون Composer) |

## وضعیت پیشرفت

- [x] **۱. طراحی دیتابیس** — `database/schema.sql` + `docs/DATABASE.md`
- [x] **۲. ساختار پایه پروژه** — Router، اتصال دیتابیس، پنل مدیریت (دسته‌بندی، برند، تنظیمات)
- [x] **۳. صفحات فروشگاه** — مدیریت محصولات، صفحه دسته‌بندی با فیلتر، جزئیات محصول، جستجو، سبد خرید
- [x] **۴. پرداخت و سفارش** — زرین‌پال (Sandbox)، ثبت سفارش، ایمیل، مدیریت سفارش‌ها در پنل
- [x] **۵. حساب کاربری و نظرات** — دفترچه آدرس، علاقه‌مندی‌ها، بازیابی رمز، ثبت و تایید نظر

## نصب

### ۱. ساخت دیتابیس
در cPanel → **MySQL Databases** یک دیتابیس و یک کاربر بسازید و کاربر را با دسترسی کامل به دیتابیس اضافه کنید.

سپس در **phpMyAdmin** به ترتیب Import کنید:
1. `database/schema.sql`
2. `database/seed.sql`
3. `database/demo-products.sql` — اختیاری، چند محصول نمونه برای دیدن سایت قبل از
   وارد کردن محصولات واقعی (روش پاک کردنشان در انتهای همان فایل نوشته شده)

> اگر دیتابیس را **پیش از افزوده‌شدن بخش شخصی‌سازی ظاهر** نصب کرده‌اید،
> یک‌بار `database/appearance.sql` را هم Import کنید تا تنظیمات رنگ و لوگو
> افزوده شوند. (اجرای آن هیچ داده‌ای را پاک نمی‌کند و اجباری هم نیست؛
> این مقادیر هنگام اولین ذخیره در پنل خودکار ساخته می‌شوند.)
>
> برای فعال‌کردن **همگام‌سازی گوگل‌شیت** هم اگر دیتابیس را از قبل نصب کرده‌اید،
> یک‌بار `database/sync-logs.sql` را Import کنید و توکن مخفی را در
> `config/config.local.php` بگذارید. راهنمای کامل در `docs/SHEET-SYNC.md`.
>
> برای فعال‌کردن **بلاگ و تنظیمات محتوایی جدید** (متن صفحه اصلی، پاپ‌آپ مشاوره،
> لینک لوکیشن) روی نصب قبلی، یک‌بار `database/content-update.sql` را Import کنید
> (امن است و داده‌ای پاک نمی‌کند). سپس برای **فیلدهای سئوی مطالب**، یک‌بار
> `database/seo-fields.sql`، و برای **آیکون دسته‌ها در مگا منو** یک‌بار
> `database/category-icon.sql` را هم Import کنید.

### ۲. آپلود فایل‌ها
همه فایل‌های پروژه را در `public_html` (یا زیرپوشه دلخواه) آپلود کنید.
مسیردهی به‌صورت خودکار تشخیص داده می‌شود و اگر پروژه در زیرپوشه باشد هم کار می‌کند.

### ۳. تنظیمات اتصال
از فایل `config/config.local.example.php` یک کپی بگیرید، نامش را به
`config/config.local.php` تغییر دهید و اطلاعات دیتابیس را وارد کنید.

### ۴. ورود به پنل
به آدرس `/admin/login` بروید:

```
ایمیل:     admin@itecho.ir
رمز عبور:  Admin@12345
```

> ⚠️ بلافاصله پس از نصب، رمز عبور مدیر را تغییر دهید.

## ساختار پروژه

```
index.php              نقطه ورود — همه درخواست‌ها از اینجا می‌گذرند
.htaccess              مسیردهی و تنظیمات امنیتی آپاچی
│
config/                تنظیمات اتصال دیتابیس (config.local.php در گیت نیست)
│
app/
├── routes.php         تعریف همه آدرس‌های سایت
├── Core/              هسته: Router، Database، Auth، View، Csrf، Flash، Mailer، Upload
├── Payment/           درگاه پرداخت (قرارداد مشترک + زرین‌پال)
├── Models/            کار با جدول‌های دیتابیس
├── Controllers/       منطق هر صفحه
│   └── Admin/         کنترلرهای پنل مدیریت
└── Views/             قالب‌های نمایش
    ├── layouts/       چارچوب کلی صفحات (site / admin / blank)
    ├── site/          صفحات فروشگاه
    ├── admin/         صفحات پنل
    └── errors/        صفحات ۴۰۴ و ۵۰۰
│
libs/PHPMailer/        کتابخانه ارسال ایمیل، فایل مستقیم و بدون Composer
│
assets/
├── css/               استایل‌ها (base مشترک + site + admin)
├── js/                جاوااسکریپت خالص، بدون کتابخانه
├── fonts/             فونت وزیرمتن به‌صورت فایل محلی (بدون CDN)
└── img/               تصاویر ثابت
uploads/               فایل‌های آپلودی (اجرای PHP در آن غیرفعال است)
database/              فایل‌های SQL
docs/                  مستندات
```

### چطور یک صفحه جدید اضافه کنم؟

۱. یک مسیر در `app/routes.php` اضافه کنید:
```php
$router->get('/my-page', 'MyController@index');
```

۲. کنترلر را در `app/Controllers/MyController.php` بسازید:
```php
class MyController extends Controller
{
    public function index(): void
    {
        $this->view('site/my-page', ['title' => 'عنوان صفحه'], 'site');
    }
}
```

۳. قالب را در `app/Views/site/my-page.php` بنویسید.

## نکات امنیتی رعایت‌شده

- همه کوئری‌ها با **Prepared Statement** اجرا می‌شوند (جلوگیری از SQL Injection)
- همه خروجی‌ها با تابع `e()` ایمن‌سازی می‌شوند (جلوگیری از XSS)
- همه فرم‌های POST **توکن CSRF** دارند
- رمزها با `password_hash()` ذخیره می‌شوند
- پس از ۵ تلاش ناموفق ورود، حساب ۲ دقیقه قفل می‌شود
- پوشه‌های `app`، `config` و `database` از دسترسی مستقیم مرورگر مسدود شده‌اند
- اجرای فایل PHP در پوشه `uploads` غیرفعال است

## قابلیت‌های پیاده‌سازی‌شده

**فروشگاه**
- صفحه دسته‌بندی با فیلتر برند، قیمت، وضعیت نو/کارکرده، ویژگی‌ها (رنگ/حافظه/رم) و «فقط موجودها»
- مرتب‌سازی: جدیدترین، ارزان‌ترین، گران‌ترین، پرفروش‌ترین، بیشترین امتیاز
- صفحه محصول با گالری، انتخاب تنوع و نمایش **داینامیک قیمت و موجودی**
- جستجو در نام، برند (فارسی و انگلیسی) و کد کالا + پیشنهاد زنده هنگام تایپ
- سبد خرید برای مهمان و کاربر، با ادغام خودکار سبد پس از ورود

**خرید و پرداخت**
- ثبت‌نام با کد تایید ۶ رقمی ایمیل، ورود، و اجباری شدن ورود فقط هنگام تسویه‌حساب
- تسویه‌حساب با دو روش تحویل: دریافت حضوری (هزینه ثابت) و ارسال با پست
- پرداخت آنلاین زرین‌پال با ساختار قابل تعویض (تبدیل تست به واقعی فقط با تغییر تنظیمات)
- کسر خودکار موجودی پس از پرداخت و بازگشت آن هنگام لغو یا مرجوعی
- پرداخت تکمیلی هزینه ارسال پستی با لینک یکتای ایمیل‌شده
- ایمیل کد تایید، تایید سفارش و لینک پرداخت ارسال

**حساب کاربری**
- پیشخوان با خلاصه سفارش‌ها، علاقه‌مندی‌ها و آدرس‌ها
- دفترچه آدرس چندتایی با آدرس پیش‌فرض (هنگام تسویه‌حساب خودکار انتخاب می‌شود)
- علاقه‌مندی‌ها با دکمه قلب روی کارت محصول (بدون بارگذاری دوباره صفحه)
- ویرایش پروفایل و تغییر رمز عبور
- بازیابی رمز عبور با کد ۶ رقمی ایمیل

**نظرات**
- ثبت نظر و امتیاز فقط توسط کسانی که محصول را خریده‌اند
- نمایش نشان «خریدار تاییدشده»
- هیچ نظری بدون تایید مدیر در سایت دیده نمی‌شود
- میانگین امتیاز محصول با تایید یا رد هر نظر خودکار محاسبه می‌شود

**پنل مدیریت**
- مدیریت کامل محصولات: تصویر اصلی و گالری، مشخصات فنی، تنوع با قیمت و موجودی مستقل
- آپلود امن تصویر: بررسی واقعی بودن فایل، نام تصادفی، و کوچک کردن خودکار عکس‌های بزرگ
- مدیریت سفارش‌ها: تغییر وضعیت با کنترل انتقال‌های مجاز، ثبت هزینه ارسال، کد رهگیری
- تایید یا رد نظرات به همراه امکان پاسخ فروشگاه
- مدیریت دسته‌بندی‌ها (منبع مگا منو)، برندها و تنظیمات

**شخصی‌سازی ظاهر** (بدون نیاز به کدنویسی)
- **رنگ و تم:** انتخاب رنگ برند و رنگ تاکیدی با تم‌های آماده و پیش‌نمایش زنده
- **لوگو و نام:** آپلود لوگو و فاوآیکون و تغییر نام سایت
- **اسلایدر صفحه اصلی:** افزودن/ویرایش/حذف اسلایدها با تصویر جداگانه برای موبایل، لینک و ترتیب
- **پس‌زمینه دسته‌های اصلی:** آپلود تصویر پس‌زمینه برای کارت هر دسته در صفحه اصلی

**محتوا و ظاهر بیشتر**
- **مجله آیتکو (بلاگ):** مدیریت کامل مقاله‌ها با **تحلیل‌گر سئوی زنده** (امتیاز، بررسی
  کلمه کلیدی، طول عنوان/توضیح، پیش‌نمایش نتیجه‌ی گوگل) شبیه Yoast
- خروجی **سئوی کامل** روی صفحات: تگ canonical، Open Graph، Twitter Card و داده‌ی
  ساختاریافته‌ی Article (JSON-LD)، به‌همراه `sitemap.xml` و `robots.txt`
- **مدیریت صفحات:** افزودن صفحه‌ی جدید، ویرایش متن همه‌ی صفحات و حذف
- **ویرایش متن صفحه اصلی** (عنوان و متن بخش قهرمان) از پنل
- **هدر چسبان** و بازبینی‌شده برای نمایش درست در موبایل
- **ویجت تماس چسبان** (تلفن، واتساپ، تلگرام، موقعیت) با شماره/لینک‌های قابل ویرایش
- **پاپ‌آپ مشاوره** در اولین ورود هر کاربر، با متن و شماره‌ی قابل ویرایش
- **پس‌زمینه مگا منو** و **تگ‌لاین کارت دسته‌بندی**، و تعداد محصول در هر صفحه (از قبل)
- **ویدیوی پس‌زمینه‌ی استیکی برای هر صفحه** (خانه، مجله، هر دسته‌بندی و هر صفحه) که با
  اسکرول محو می‌شود — با نسخه‌ی جدا برای دسکتاپ و موبایل (از بخش «ویدیوی صفحات»)
- **تم نئونی سبک** روی دکمه‌ها، کارت‌ها و منو (وفادار به رنگ برند، بدون شلوغی)

**همگام‌سازی محصولات (گوگل‌شیت + آپلود CSV)**
- به‌روزرسانی خودکار قیمت و موجودی (و ساخت محصول ساده‌ی جدید) از یک گوگل‌شیت خصوصی،
  دو بار در روز، از طریق نقطه پایانی امن `api/sheet-sync.php` با توکن مخفی
- **آپلود دستی فایل CSV** با همان ستون‌ها از داخل پنل (با گزینه‌ی اختیاری غیرفعال‌سازی
  محصولاتِ نبوده در فایل)
- گزارش هر اجرا در پنل، صفحه‌ی «همگام‌سازی محصولات» دیده می‌شود
- راهنمای کامل + کد اسکریپت گوگل در [`docs/SHEET-SYNC.md`](docs/SHEET-SYNC.md)
